Project 1: SOC incident response, three shift reports

Three end-of-shift reports from a simulated security operations centre.

Triage, timelines and containment plans

Role: SOC analyst (simulated) · Deliverable: Word reports

The task

For each shift I reviewed the alerts, separated real threats from benign activity, reconstructed what happened, and wrote a report a manager could act on: executive summary, timeline, MITRE ATT&CK mapping, and recommended next steps.

Shifts

Shift 1: dropper on a workstation

A fake “design suite” zip led to a process tree masquerading as a legitimate application, with a dropped configuration file.

  • Recommended isolating the host and terminating the malicious process.
  • Recommended sweeping the wider fleet for the same indicators.
  • Recommended interviewing the user to find how the file arrived.
Shift 2: password spray to data exfiltration

The most complete attack chain I investigated:

  1. Password spray against the VPN, which had no MFA.
  2. Credential dump from LSASS.
  3. Lateral movement to a domain controller.
  4. About 500 MB of finance data exfiltrated.
  5. Persistence through a rogue admin account, a SYSTEM scheduled task, and RDP enabled.

Each step was mapped to MITRE ATT&CK.

Shift 3: ransomware over SMB

Ransomware spread over SMB to three hosts. I traced patient zero to a dormant scheduled task left behind by an earlier intrusion, and explained why the patch reboot only triggered it rather than caused it.

Containment was ordered by urgency: isolate hosts, block command-and-control, pause the patch rollout, preserve evidence, then remediate.

What I learned

Alert triage, timeline reconstruction, root cause analysis, prioritising containment, and writing for both technical and non-technical readers.

Project 2: Malware analysis, static and dynamic

A full analysis of a provided Windows sample, in an isolated lab.

.NET remote access trojan (AsyncRAT/XWorm family)

Role: malware analyst · Deliverable: static report, dynamic report, IoC bundle

Safety setup

All work was done in an isolated Windows 10 VM with a clean snapshot, host-only networking, and monitoring from System Informer, Wireshark and Regshot. The sample was never run on my own machine.

Static analysis

  • Identified the file type by signature rather than extension.
  • Calculated MD5, SHA-1 and SHA-256, then checked VirusTotal and MalwareBazaar, which pointed to the AsyncRAT/XWorm family.
  • Reviewed PE headers, compile timestamp, section entropy and the import table.
  • Found a string suggesting an anti-sandbox hosting check.
  • Concluded the sample relied on managed-code obfuscation instead of a native packer.

Dynamic analysis

No execution was observed in the lab. I troubleshot the environment (including the .NET runtime) and documented two possible explanations with confidence levels, rather than claiming behaviour I hadn’t seen.

Outputs

An indicator-of-compromise table, a STIX 2.1 bundle, a MITRE ATT&CK mapping, and detection recommendations.

  • Wireshark
  • Regshot

Project 3: Web application penetration test

NahamStore, an intentionally vulnerable shop on TryHackMe.

10 confirmed vulnerabilities with a remediation roadmap

Role: penetration tester · Deliverable: findings deck · Standards: OWASP Top 10, CWE

Result

7 High3 Medium

Every finding includes the request, the payload, the business impact, its CWE and OWASP mapping, and a specific fix.

Findings

  • Reflected and stored cross-site scripting (XSS)
  • Two open redirects
  • Two insecure direct object references (IDOR)
  • Cross-site request forgery (CSRF), with a token that was not enforced
  • Server-side request forgery (SSRF), including a filter bypass
  • Local file inclusion through path traversal
  • XML external entity injection (XXE)

Attack chains

I showed how an open redirect, an IDOR and stored XSS can be combined to take over accounts and expose data, which matters more than any single bug on its own.

Roadmap

Fixes were grouped into 7-day, 30-day and 90-day actions so the client could prioritise.

  • Burp Suite

  • ffuf
  • gobuster
  • Arjun
  • CyberChef
